## “返回”与授权取消

增加 `POST /auracap/api/github/device/:id/cancel`，只结束指定的未完成连接流程。取消会中止等待与请求，并等待该流程退出，之后才向界面确认结束；迟到的响应不能继续提交连接信息。已结束或不存在的流程可重复取消，不影响其他连接。

授权准备先使用新授权检查账号、仓库和 Release，准备完成才提交本地连接信息。准备期间取消，不覆盖已有连接与凭据。已经进入本地提交段时，取消等待提交结果：若连接已经完成，界面展示实际连接状态，不把它再断开。凭据服务存在但写入失败时明确失败，保留原连接，不再静默改用另一份状态并报成功。

前端取消和轮询采用同一请求版本边界；取消失败后可以继续检查。连接成功后先取得实际连接信息，再退出授权页，避免短暂跳回欢迎页。

## 备份接入中的必要调整

备份格式、内容替换、附件重建及“不重新调用模型”的规则保持。联调发现导出在清理临时快照之前就公布 `DOWNLOAD_READY`，短时间内仍占用执行名额；现改为清理完成后公布就绪，连续选择不同导出类型不会因该时序误报忙碌。

恢复选择“重新选择”时只取消旧预览任务并更换文件，不先关闭、再重开同一个窗口。恢复阶段切换后，如果原控件已经移除，焦点回到当前窗口。内容库真正切换时继续清除旧库草稿；仅打开、关闭或检查恢复文件则保留编辑状态。

菜单按最终宽度测量高度，限制上下左右边界，避免窄窗口换行后底部被截断。定位与焦点顺序一起处理，保留方向键、Escape 和回焦。

## 截图反馈后的修正

移除片刻详情操作栏额外的上边框，保留相关片刻自身的行边界和现有布局。分组操作由一个忙碌布尔值改为包含操作类型、目标组的当前操作状态：禁用状态由它派生，进度文案只属于实际执行的操作，且只显示在目标组。“拆分”不再错误显示“正在合并…”，非执行中的按钮保留名称并禁用。

针对真实生产客户端完成 7 项浏览器检查：相关片刻、重新合并等待与成功、失败恢复、真实隔离 API 拆分、首次合并、卡片弹窗、手动合并入口。模型合并响应使用模拟，未调用模型、未写用户内容库。结果与修正截图位于 [专项验证目录](/Users/massif/dsh-auracap/output/playwright/detail-actions-20261111/)。本节为后续代码修正，前述静态对照和安装包保留原交付快照。
