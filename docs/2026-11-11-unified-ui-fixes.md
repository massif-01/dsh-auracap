# AuraCap 审查问题修复与页面验证

日期：2026-11-11。依据：[审查报告](/Users/massif/dsh-auracap/docs/2026-11-11-unified-ui-full-review.md)。本轮已修改生产代码、检查实际组件页面，并生成同一源码版本的独立预览与安装包；没有提交、发布或主动安装到用户正在使用的 Harness。

## 实施边界

保留主页、列表与详情的几何布局，设置单列、功能顺序与最大宽度，以及灰色小标题。实测小标题仍为 `rgb(129, 133, 140)`，对应 `#81858c`。没有增加依赖，没有更改备份文件格式、完整替换规则或恢复事务。

生产改动为 `client.js`、`index.js`、`backup/tasks.js`。最后一项只把手机连接阻塞恢复的原因明确为 `PHONE_CONNECTION_PENDING`，使前后端能提供同一含义的操作提示；其他备份模块与本轮开始时相同。开发预览服务接回真实授权状态，现有授权测试增加两个对应已复现问题的用例。

## 收敛结果

| 审查项 | 本次处理 |
| --- | --- |
| R01 未完成授权 | 服务端将并发发起接到同一个未完成流程；状态接口提供其公共状态。前端重载后接回，进行中禁止重复发起，返回可结束实际流程 |
| R02 授权卸载边界 | 本地提交一旦开始，凭据与仓库元数据一起完成；卸载或断开等待这一结果，不在中途仅跳过元数据，也不再发起该旧流程的后续同步 |
| R03 草稿覆盖 | 上下文未载入时不创建空编辑器；读取完成才进入阅读或编辑。编辑草稿与已保存内容分开，后续读取不会重置草稿；读写时序也排除迟到批次 |
| R04 设置反馈 | 保存错误留在上下文编辑器，权限与索引错误留在各自区域；本地设置读取失败在设置内提供重新载入 |
| R05 备份接续 | 服务端活动任务可以替换过期的本机记录；旧任务轮询不能覆盖已接回的新任务，重新检查能恢复实际可操作状态 |
| R06 分组状态 | 进度与错误共同属于带类型和目标身份的一次操作；切换组不携带另一组的进度或失败 |
| R07 首次读取失败 | 明确结束初始载入，展示实际错误，并保留重新载入、电脑导入与直接恢复；重试成功后按真实条目和洞察进入页面 |
| R08 弹窗焦点 | 设置、恢复、实体、归组选择、卡片详情、图片与截图提示采用同一小型焦点逻辑。仅顶层窗口处理按键；控件禁用或移除后维持焦点；恢复关闭后仍能回到原设置入口 |
| R09 引导步骤 | 已发起下载的事实按仓库保存，与本次请求提示分开；重试下载失败或重载页面不会退回安装步骤，仍不承诺手机已经安装 |
| R10 操作语义 | “归为一组”只归组，显示含当前条目的总数；之后“合并整理”生成摘要。“撤销合并整理”明确只撤去合并结果，“拆开这组”保持原义。提交中的归组不提供可用的取消、关闭或改选 |
| R11 英文错误 | 同步请求和任务终态按同一组业务 code 呈现英文原因与下一步，包含完整包、容量、空间、连接阻塞及重新载入要求 |
| R12 连接说明 | 只有健康的长期授权才显示长期有效说明，失效和错误状态不再同时出现相反承诺 |
| R13 交付一致性 | 新预览、当前源码、打包文件和隔离安装后的文件逐一核对哈希一致；旧交付保留为历史版本 |
| V01 动作行 | 保存/取消、授权/返回采用明确的行布局，间距 12px；保存与取消点击区域均高 30px，垂直对齐，次要动作保持轻量 |
| V02 窗口层次 | 共用轻阴影与边线，保留各窗口尺寸；设置为 28px，内容弹窗为 24px 圆角，关闭控件沿用同一视觉规则 |
| V03 保存阅读态 | 直接显示当前项目上下文，较长内容可展开，进入编辑后才显示输入和保存动作 |
| 最新文案反馈 | 删除欢迎页底部重复 slogan，标题栏中的版本保留 |

样式在实际所属规则内整理，移除对应旧覆盖和失效类；没有在文件末尾叠加一批抵消规则。焦点逻辑复用于现有窗口，没有引入弹窗框架。
