# AuraCap 快捷指令搭建指南（iOS）

> 目标：在 iPhone 上做一个「截图 → 上传到 GitHub 收件箱」的快捷指令。
> 用户只需要：装一次快捷指令、粘贴一次配置、以后截图即上传。
> 配置串格式：`gh|owner/repo|token`

---

## 0. 在开始之前

1. 在 Mac 的 AuraCap 插件里打开「手机入口」，先点「复制配置」，把
   `gh|owner/repo|token` 复制到剪贴板（后面导入快捷指令时会用到）。
2. 确认 GitHub 上已经有 `owner/auracap-inbox` 私有仓库和 `auracap-inbox` Release（插件「检查 / 修复」会自动建）。

---

## 1. 新建快捷指令

1. 打开「快捷指令」App → 右上角 `+` 新建。
2. 点顶部名称，改名为 `AuraCap 截图`，选一个图标（相机/方框）。
3. 点右上角 `...`（详细信息）：
   - 打开 **在共享表单中显示**；
   - **接收** 勾选 **图像**（只要图像）；
   - 关闭「在 Apple Watch 上显示」等无关项。

---

## 2. 加一个「配置」文本（关键）

1. 在画布中添加动作 **文本**（Text）。
2. 内容先留成占位：
   ```
   gh|owner/repo|token
   ```
3. 点右上角 `...` → 找到 **导入问题 / Import Questions** → **添加导入问题**：
   - 选择这个「文本」动作；
   - 问题写：`粘贴 AuraCap 面板里的配置串（gh|owner/repo|token）`；
   - 默认值保持 `gh|owner/repo|token`。
4. 这样别人安装你的快捷指令时，会弹出输入框让他粘贴配置，不需要你手动改。

> 注意：分享前确保这个「文本」里是占位值，不要把你自己真实的 token 分享出去；导入问题会在安装时替换成用户自己的配置。

---

## 3. 取图：有输入用输入，没输入就截屏

1. 添加 **如果**（If）：
   - 条件：`快捷指令输入` **没有值**（Has No Value）。
2. 在「如果」分支里加 **截屏**（Take Screenshot）。
3. 加 **设定变量**（Set Variable）：变量名 `图像`，值选「截屏」的结果。
4. 点「否则」（Otherwise）：
   - 加 **获取输入的图像**（Get Images from Input）；
   - 加 **从列表中获取项目**（Get Item from List）：列表选上一步结果，位置 `第一项`；
   - 加 **设定变量**：变量名 `图像`，值选上一步结果。
5. 结束如果。

> 这样：从分享菜单运行时用你分享的图；从动作按钮 / 轻点背面 / 小组件运行时自动截当前屏幕。

---

## 4. 统一转成 JPEG

1. 添加 **转换图像**（Convert Image）：
   - 图像：选变量 `图像`；
   - 格式：`JPEG`；
   - 质量：`0.9`（或 0.8，体积更小）。
2. 加 **设定变量**：变量名 `上传图`，值选转换结果。

> 原因：Share Sheet 里可能是 HEIC/PNG/JPEG，插件只接受 png/jpeg/webp/gif；统一转 JPEG 最稳。

---

## 5. 解析配置

1. **拆分文本**（Split Text）：文本选「文本（配置）」，分隔符选 `自定`，填 `|`。
2. **从列表中获取项目**：列表选上一步，位置 `第 2 项` → 设定变量 `仓库全名`。
3. **从列表中获取项目**：列表选第 1 步结果，位置 `第 3 项` → 设定变量 `Token`。
4. **拆分文本**：文本选 `仓库全名`，分隔符 `自定`，填 `/`。
5. **从列表中获取项目**：位置 `第 1 项` → 设定变量 `Owner`。
6. **从列表中获取项目**：位置 `第 2 项` → 设定变量 `Repo`。

> 此时你得到：`Owner`、`Repo`、`Token` 三个变量。

---

## 6. 查收件箱 Release

1. 添加 **获取 URL 内容**（Get Contents of URL）：
   - URL：
     ```
     https://api.github.com/repos/{Owner}/{Repo}/releases/tags/auracap-inbox
     ```
     （在 URL 输入框里直接插入变量）
   - 方法：`GET`
   - 头部（Headers）：
     | 键 | 值 |
     |---|---|
     | `Authorization` | `Bearer {Token}` |
     | `Accept` | `application/vnd.github+json` |
     | `X-GitHub-Api-Version` | `2022-11-28` |
2. **设定变量** `Release响应` = 上一步结果。
3. **获取词典值**（Get Dictionary Value）：键 `id`，来源 `Release响应` → 设定变量 `ReleaseID`。
4. **如果** `ReleaseID` **没有值**：
   - **显示通知**：`AuraCap：找不到收件箱 Release，请在 Mac 插件里点「检查 / 修复」`；
   - **停止此快捷指令**。

---

## 7. 生成唯一文件名

1. **当前日期**（Current Date）。
2. **格式化日期**（Format Date）：
   - 日期选上一步；
   - 格式选 `自定`，填 `yyyyMMdd-HHmmss`。
3. **文本**：内容写
   ```
   AuraCap-{格式化日期}.jpg
   ```
   → 设定变量 `文件名`。

> 文件名必须唯一，否则 GitHub 会返回 422（同名 asset 已存在）。

---

## 8. 上传到 Release Assets

1. 添加 **获取 URL 内容**：
   - URL：
     ```
     https://uploads.github.com/repos/{Owner}/{Repo}/releases/{ReleaseID}/assets?name={文件名}
     ```
   - 方法：`POST`
   - 头部：
     | 键 | 值 |
     |---|---|
     | `Authorization` | `Bearer {Token}` |
     | `Accept` | `application/vnd.github+json` |
     | `Content-Type` | `image/jpeg` |
   - **请求体**（Request Body）：选 **文件（File）**，文件选变量 `上传图`。
2. **设定变量** `上传响应` = 上一步结果。
3. **获取词典值**：键 `id`，来源 `上传响应` → 设定变量 `AssetID`。

---

## 9. 结果通知

1. **如果** `AssetID` **有值**：
   - **显示通知**：`AuraCap：已上传，回 Mac 上看总结。`
2. **否则**：
   - **显示通知**：`AuraCap：上传失败，请检查网络或重新连接 GitHub。`（可以把 `上传响应` 一起显示出来排查）
3. **停止此快捷指令**。

---

## 10. 分享给用户

1. 先把「配置」文本恢复成占位 `gh|owner/repo|token`；
2. 点快捷指令右上角 `...` → **分享** → **拷贝 iCloud 链接**；
3. 把这个链接交给插件（后面插件第 1 步的「安装快捷指令」按钮会用它）。

用户安装时：

1. 先在自己 Mac 的插件里点「复制配置」；
2. 打开你分享的 iCloud 链接 → 添加到快捷指令；
3. 安装向导会弹出导入问题 → 粘贴配置；
4. 之后从分享菜单、动作按钮、轻点背面运行即可。

> 如果 iOS 提示“无法打开不受信任的快捷指令”，去
> 设置 → 快捷指令 → 打开「允许不受信任的快捷指令」。

---

## 11. 自己先测一遍

1. 在 iPhone 上装好快捷指令并粘贴配置；
2. 随便截一张图 → 分享 → 选 `AuraCap 截图`；
3. 应弹出「已上传」通知；
4. Mac 上的 AuraCap 面板点「立即同步」或等 60 秒轮询；
5. 应该出现一条新碎片，GitHub Release 里的 asset 被删掉。

常见错误：

| 现象 | 原因 |
|---|---|
| 401 | token 失效；在插件里断开后重新连接 |
| 404 | 仓库/Release 不存在；插件里点「检查 / 修复」 |
| 422 | 文件名重复；确认时间戳格式正确 |
| 上传成功但插件没收到 | 检查插件的队列状态，点「立即同步」；或确认 Release 是 `auracap-inbox` |
| 分享菜单里没有快捷指令 | 快捷指令设置里没打开「在共享表单中显示」，或接收类型不是「图像」 |

---

## 12. 后续可以增强

- 多张图一起分享：用 `重复每个项目` 包住第 4–9 步；
- 失败重试：把上传包在 `重复 3 次` 里；
- 离线排队：目前 iOS 快捷指令没有可靠本地队列，失败后只能通知重试（后续可在插件侧做“补传”入口）；
- 二维码写入配置：后续插件可以直接生成 `shortcuts://run-shortcut?...&text=<配置>` 的二维码，省去导入问题那一步。
